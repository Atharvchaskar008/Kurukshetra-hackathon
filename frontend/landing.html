Find answers to common questions about DepScan AI. If you can't find what you're looking for, explore our documentation or start a scan.

DepScan AI is an automated, zero-code-execution Software Supply Chain Security Analyzer and Remediation Engine. It statically inspects polyglot source code and dependency manifests to identify direct and transitive CVE vulnerabilities, typosquatting indicators, build provenance flaws, and calculates mathematical blast radius across services, while generating 1-click AI remediation patches.
DepScan constructs a full Directed Acyclic Graph (DAG) using NetworkX from your project manifests. When a vulnerable or poisoned package is detected, the engine executes recursive topological traversal to trace all upstream parent services and downstream dependents. An exact Blast Radius Impact Score (0.10 to 1.00) is computed based on transitive nesting depth, reverse dependency density, and critical-path reachability.
Traditional dependency audit tools often invoke package manager CLI commands that execute arbitrary dynamic lifecycle scripts (such as postinstall in npm or setup.py in Python), exposing the host machine to immediate remote code execution or credential harvesting. DepScan guarantees 100% safety through static Abstract Syntax Tree (AST) parsing and deterministic manifest deserialization, never executing npm install, pip install, or arbitrary setup hooks.
DepScan delivers simultaneous, first-class polyglot inspection across 8 major package ecosystems: npm (JavaScript & TypeScript), PyPI (Python), Go (go.mod, go.sum), Maven (Java pom.xml & Gradle), Cargo (Rust Cargo.toml & lock), Packagist (PHP Composer), NuGet (.NET / C#), and RubyGems (Ruby Gemfile). Monorepos with multiple languages are scanned concurrently.
DepScan is fully functional offline without any AI API key. All deterministic security features — static AST parsing, live OSV.dev and GHSA advisory matching, NetworkX DAG blast radius graphing, typosquatting heuristic detection, and P0–P3 risk gating — run autonomously and deterministically on your local system. When a Google Gemini API key is configured, it unlocks optional generative capabilities: plain-English vulnerability explainers, real-world attack scenario simulations, and 1-click automated unified Git diff patch synthesis.
